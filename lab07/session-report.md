## Саадууд (issues)

1. **Дэлгэцийн хэмжээ:** Браузерын цонхыг жижигрүүлэхэд «Нэмэх» товч дараагийн мөрөнд шилжиж, хүснэгтийн баганууд шахагдсан. Энэ нь интерфейсийн байрлал болон харагдацыг шалгахад хүндрэлтэй байв.

2. **Номын тоолуурын зөрүү:** Хүснэгтэд 3 ном байхад «Нийт ном: 4» гэж харагдсан. Иймээс номын бодит тоог хүснэгтийн мөрүүдтэй харьцуулан шалгах шаардлагатай болсон.

3. **Өгөгдлийн алдаа:** Давхардсан ном нэмэгдэж, хүчингүй оны утга `NaN` гэж харагдсан. Энэ нь дараагийн туршилтуудад өгөгдлийн төлөвийг анхаарч шалгах шаардлага үүсгэсэн.

4. **API-ийн алдааны хариу:** Буруу JSON өгөгдөл илгээхэд сервер `HTTP 400` биш `HTTP 200 OK` буцаасан. Үүнээс шалтгаалан хүсэлт амжилттай эсэхийг зөвхөн HTTP статус кодоор дүгнэх боломжгүй байв.
