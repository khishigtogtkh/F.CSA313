# Lab05 — API систем тест

Нэр: С.Хишигтогтох  
Оюутны код: B232270806

## Тестийн дизайн

Тусад нь тестлэх функц нь `POST /registrations`. Тестийн сонголт, төлөөлөх утга, спецификацийг доор өгсөн. Спецификаци бүрийн ID Postman collection дахь хавтасны нэрийн эхэнд байна.

### Сонголт ба төлөөлөх утга

| Сонголт | Эквивалент анги | Төлөөлөх утга |
| --- | --- | --- |
| `studentID`-ийн хүчинтэй байдал | Идэвхтэй, идэвхгүй, байхгүй | `status: "active"`, `status: "inactive"`, үүсгээгүй оюутны ID |
| Оюутны үзсэн хичээл | Урьдач нөхцөлийг хангана, хангахгүй | Бүх шаардлагатай кодтой `coursesTaken`, хэсэгчилсэн жагсаалт, `[]` |
| `courseID`-ийн хүчинтэй байдал | Байгаа, байхгүй | PUT-аар үүсгэсэн ID, үүсгээгүй хичээлийн ID |
| Урьдач хичээлийн хамрагдалт | Бүгдийг үзсэн, огт үзээгүй, заримыг үзсэн, урьдачгүй | `prerequisites: ["CS201", "CS202"]`-ыг `["CS201", "CS202"]`, `[]`, `["CS201"]`-тай харьцуулах, эсвэл `prerequisites: []` |
| Хүсэлтийн формат | Хоёр ID байгаа, талбар дутуу, JSON буруу | Хоёр ID-тай JSON, зөвхөн `studentID`-тай JSON, хаагдаагүй JSON объект |

### Спецификаци

| ID | Төрөл | Setup ба POST оролт | HTTP | `result` | Нэмэлт oracle |
| --- | --- | --- | --- | --- | --- |
| C01 | Амжилттай | Идэвхтэй `B231234567` оюутан `CS201` үзсэн. `CS313` нь `CS201` шаарддаг | 201 | `OK` | Тоон `registrationID` |
| C02 | Оюутан байхгүй | Хичээл байгаа. Үүсгээгүй оюутны ID илгээнэ | 200 | `ERROR_NO_STUDENT` | |
| C03 | Оюутан идэвхгүй | Идэвхгүй оюутан урьдач хичээлээ үзсэн. Сонгосон хичээл байгаа | 200 | `ERROR_INACTIVE_STUDENT` | |
| C04 | Хичээл байхгүй | Идэвхтэй оюутан байгаа. Үүсгээгүй хичээлийн ID илгээнэ | 200 | `ERROR_NO_COURSE` | |
| C05 | Урьдач дутуу | Идэвхтэй оюутан `CS201` үзсэн. Хичээл `CS201`, `CS202` шаарддаг | 200 | `ERROR_PREREQUISITES` | `missing` яг `["CS202"]` |
| C06 | Давхар алдаа | Идэвхгүй оюутан ба үүсгээгүй хичээлийн ID | 200 | `ERROR_INACTIVE_STUDENT` | Идэвхийг хичээлийн оршин байхаас өмнө шалгана |
| C07 | Давхар алдаа | Идэвхгүй оюутны `coursesTaken: []`. Хичээл `CS201`, `CS202` шаарддаг | 200 | `ERROR_INACTIVE_STUDENT` | Идэвхийг урьдач хичээлээс өмнө шалгана |
| C08 | Хязгаар | Идэвхтэй оюутны `coursesTaken: []`, хичээлийн `prerequisites: []` | 201 | `OK` | Тоон `registrationID` |
| C09 | Хязгаар | Идэвхтэй оюутан ба хичээл байгаа. POST биед `studentID` илгээнэ | 400 | `ERROR_BAD_REQUEST` | |

Хавтас бүр өөрийн PUT хүсэлтээр шаардлагатай өгөгдлийг бүрдүүлээд POST-оо ажиллуулна. Байхгүй байх ёстой ID-уудыг ямар ч setup үүсгэдэггүй. PUT нь тухайн бичлэгийг бүтнээр нь шинэчилдэг. Амжилттай бүртгэлүүд нэг серверийн процесс дотор хуримтлагдах тул ID-ийн төрлийг шалгана.
