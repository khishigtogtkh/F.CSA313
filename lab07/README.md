## Ажиллуулах

```bash
cd /home/hishigtogtokh/F.CSA313/lab07
node -v
node app.js
```

`node -v`-ийн шалгасан гаралт: `v22.23.2`. Аппын хаяг: <http://localhost:3000>. Нэмэлт npm dependency шаардахгүй. Өгөгдөл санах ойд хадгалагддаг тул `Ctrl+C` дараад `node app.js`-ийг дахин ажиллуулахад анхны 3 ном сэргээнэ. Браузерыг refresh хийх нь өгөгдлийг цэвэрлэхгүй.
