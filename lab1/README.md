## Хийгдсэн тестүүд

Нийт 3 автомат тест бичсэн.

### 1. Амжилттай нэвтрэх тест

`standard_user` хэрэглэгч болон зөв нууц үг ашиглан нэвтрэх үйлдлийг автоматжуулсан.

Нэвтрэлт амжилттай болсныг:

- `Products` текст харагдаж байгаа эсэх
- Login хийсний дараа хэрэглэгч зөв хуудас руу шилжсэн эсэхийг URL-аар шалгасан.

зэрэг assertion ашиглан шалгасан.

Тестийн төгсгөлд logout хийж, login хуудас руу буцсан эсэхийг мөн шалгасан.

### 2. Амжилтгүй нэвтрэх тест

Зөв username болон буруу password ашиглан нэвтрэхийг оролдсон.

Нэвтрэлт амжилтгүй болсон үед тохирох алдааны мессеж харагдаж байгаа эсэхийг assertion ашиглан шалгасан.

### 3. Нэвтэрсний дараах үйлдлийн тест

Хэрэглэгч амжилттай нэвтэрсний дараа нэг бүтээгдэхүүнийг shopping cart-д нэмсэн.

Cart дээрх барааны тоо `1` болсон эсэхийг шалгасан.

Тестийн төгсгөлд logout хийж, login хуудас руу буцсан эсэхийг шалгасан.
