## Саадууд (issues)

1. **Дэлгэцийн хэмжээ:** Браузерын цонхыг жижигрүүлэхэд «Нэмэх» товч дараагийн мөрөнд шилжиж, хүснэгтийн баганууд шахагдсан. Энэ нь интерфейсийн байрлал болон харагдацыг шалгахад хүндрэлтэй байв.

2. **Номын тоолуурын зөрүү:** Хүснэгтэд 3 ном байхад «Нийт ном: 4» гэж харагдсан. Иймээс номын бодит тоог хүснэгтийн мөрүүдтэй харьцуулан шалгах шаардлагатай болсон.

3. **Өгөгдлийн алдаа:** Давхардсан ном нэмэгдэж, хүчингүй оны утга `NaN` гэж харагдсан. Энэ нь дараагийн туршилтуудад өгөгдлийн төлөвийг анхаарч шалгах шаардлага үүсгэсэн.

4. **API-ийн алдааны хариу:** Буруу JSON өгөгдөл илгээхэд сервер `HTTP 400` биш `HTTP 200 OK` буцаасан. Үүнээс шалтгаалан хүсэлт амжилттай эсэхийг зөвхөн HTTP статус кодоор дүгнэх боломжгүй байв.

# Charter

**Судлах:** Уншлагын жагсаалт аппликейшний ном нэмэх, хайх, устгах, өгөгдөл харуулах болон API-ийн ажиллагаа.

**Ашиглан:** Зөв болон буруу оролт, хоосон талбар, хязгаарын утга, давхардсан өгөгдөл, хэрэглэгчийн интерфейсийн шалгалт болон curl API хүсэлт.

**Илрүүлэх:** Өгөгдлийн баталгаажуулалт, бизнес логик, интерфейс, тооцоолол болон API-ийн алдаатай ажиллагаа.

## Сонгосон аялалууд

**1. Supermodel (GUI)**

Интерфейсийн товч, өнгө, хүснэгтийн бүтэц, текст болон өгөгдлийн харагдацыг шалгахад тохиромжтой.

**2. Saboteur (API)**

Санаатайгаар буруу хүсэлт илгээж API-ийн алдаа боловсруулах ажиллагаа болон өгөгдлийн хамгаалалтыг шалгахад тохиромжтой.

## Хүлээгдэж буй үр дүн

- Аппликейшний үндсэн функцуудыг шалгах.
- Дор хаяж 3 өөр согог илрүүлж, дахин гаргах алхмыг тодорхойлох.

## Хэсэг E — Дүгнэлт (Debrief)

Уншлагын жагсаалт аппын номын жагсаалт, он харуулах формат, устгах товч болон API-ийн алдааны хариунд тодорхой зөрчил ажиглагдсан.

Supermodel аяллаар харагдах байдалд хамаарах BUG-01 (номын тоолуур), BUG-02 (оны формат), BUG-03 (устгах товчны өнгө) гэсэн гурван согогийг баримтжуулсан.

Эдгээрээс Supermodel нь одоогоор хамгийн олон баталгаажуулсан согог илрүүлсэн аялал байв.

Ном нэмэхтэй холбоотой GUI шалгалтын зурагт ижил нэр, зохиолчтой хоёр мөр болон `NaN` он ажиглагдсан боловч BUG-04, BUG-05-ийн яг оруулсан утгыг дахин баталгаажуулах шаардлагатай.

Saboteur аяллаар буруу JSON бүхий POST хүсэлт илгээхэд `HTTP 200 OK` буцсан BUG-06-ийг илрүүлсэн.

Charter-ийн үндсэн шалгалтаас гадуур нарийн дэлгэцэд товчны байрлал өөрчлөгдөхийг ажигласан ч үүнийг дангаар нь согог гэж бүртгээгүй.

Дараагийн session-д зохиолчоор хайх, 1000 болон 2100 оны хязгаар, маш урт текст, бүх линк болон давхардсан номын нөхцөлийг илүү нарийвчлан шалгана.

Лаборатори №1-ийн Playwright тестээр номын тоолуур, оны формат, давхардал, хүчингүй оролт болон HTTP статусын зөрүүг автомат шалгалтаар илрүүлэх боломжтой.

Устгах товчны өнгө, жижиг дэлгэцийн харагдац, мессежийн ойлгомжтой байдлыг хүний нүдээр үнэлэх нь хэрэгтэй боловч CSS шалгалт болон визуал харьцуулалтаар заримыг нь автоматжуулж болно.

Иймээс бодит screenshot, API-ийн бүтэн хариу, шинээр асаасан апп дээр давтагдах алхмыг хамтад нь хадгалах нь тестийн үр дүнг найдвартай болгоно.
