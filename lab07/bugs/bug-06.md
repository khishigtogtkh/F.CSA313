# BUG-06: Буруу JSON бүхий POST хүсэлт HTTP 400 биш HTTP 200 буцааж байна

Орчин: Уншлагын жагсаалт v2.0; браузер: [бодит нэр, хувилбар]; үйлдлийн систем: WSL2 / [яг хувилбар]; огноо: 2026-10-20.
Урьдчилсан нөхцөл: `node app.js`-ийг зогсоож шинээр асаасан, анхны 3 номтой төлөв.

## Дахин гаргах алхам

1. `node app.js`-ийг шинээр асааж ажиллуул.
2. Өөр Terminal дээр `curl -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" -d "not-json"` ажиллуул.
3. Хариуны HTTP статус мөр болон JSON биеийг шалга.
4. Бүтэн гаралтыг `evidence/bug-06-curl.txt` файлд хадгал.

**Хүлээгдэж байсан:** Буруу JSON биетэй POST хүсэлтэд `HTTP/1.1 400 Bad Request` хариу ирнэ.

**Бодит үр дүн:** Таны илгээсэн терминалын гаралт `HTTP/1.1 200 OK`, `{"result":"OK"}` гэж гарсан (2026-10-20, 04:34:03 GMT).

**Ноцтой байдал:** Major — Хүчингүй хүсэлтийг амжилттай гэж мэдээлснээр API хэрэглэгч төөрөгдөнө.
