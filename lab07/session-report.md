## Үр дүн, нэмэлт ажиглалт

- BUG-01–BUG-06 бүгд дахин гарсан. BUG дугаарууд `bugs/` доторх тайлангуудтай таарна.
- Давхардлыг `Clean Code` / `Robert C. Martin` / `2008` гэсэн зөв онтой оролтоор тусгаарлан батлав (BUG-04).
- Хүчингүй оныг `Invalid Year Probe` / `Session Tester` / `abc` гэсэн тусдаа оролтоор батлав (BUG-05).
- Хоосон оролт нэмэгдэж он `0` харагдсан; `999`, `2101`, `2008.5` мөн нэмэгдсэн. Энэ нь оны баталгаажуулалтын нэмэлт ажиглалт; BUG-05-д баримтжуулсан үндсэн оролт нь `abc`.
- Хязгаарын зөв утга `1000`, `2100` нэмэгдсэн. Хамгийн шинэ оны статистик `2100` утга дээр зөв шинэчлэгдсэн.
- Зохиолч `Robert C. Martin`, гарчгийн хэсэг `Тунгалаг`, бүтэн `Clean Code` хайлтууд тус бүр 1 мөр буцаасан. `clean code` болон `NoSuchBook-20261025` хоосон; хоосон хайлт 3 мөр сэргээсэн. Том/жижиг үсгийн шаардлага тусдаа баталгаажаагүй тул шинэ bug гэж ангилаагүй.
- Бүх номыг устгахад хүснэгт хоосорсон ч тоолуур `1` хэвээр (BUG-01). Устгах үйлдлийн мессеж «Ном нэмэгдлээ» байсан.
- 375px өргөнд document 410px болж overflow ажиглагдсан; [зураг](screenshots/narrow-viewport.png) хадгалсан.
- `/old` линк HTTP 500 буцаасан. Энэ нэмэлт ажиглалтыг шинэ bug report болгон ангилаагүй.

## Саад, хамрах хүрээ, үлдсэн ажил

Браузерын socket sandbox-д хориглогдсон тул зөвшөөрөлтэйгээр Chromium болон локал Node серверийг ажиллуулсан. Өгөгдөл санах ойд байдаг учраас бүлэг бүрийг сервер дахин асааж тусгаарласан.

Гүйцэтгэл нь AI агентын удирдсан Chromium headless болон curl шалгалт; хүний гараар хийсэн exploratory session биш. Өөр браузер, бодит төхөөрөмж, production орчинд шалгаагүй. Бизнес болон визуал хүлээлтүүдийг өмнөх bug report-ийн шалгуураар үнэлсэн.

**Үлдсэн шаардлага:** charter-ийн дагуу бодит 60 минутын exploratory session явуулж, явцад нь оролт/үр дүн/саатал/цагийн задаргааг тасралтгүй тэмдэглэх. Энэ богино дахин шалгалт нь зургаан bug report болон evidence-ийг засах нотолгоо болсон боловч 60 минутын шаардлагыг орлохгүй.
